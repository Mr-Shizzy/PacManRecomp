PacManRecomp 1.1.1 for Windows
==============================

Pac-Man for the NES, rebuilt as a real Windows game, with a launcher,
extras, cheats and easy modding. For Windows 10 and 11 (64-bit) only.

This download does NOT contain the game itself: you need your own copy of
the Pac-Man ROM. Nothing to install, and no internet needed.


HOW TO PLAY
  1. Unzip the download somewhere, e.g. your Desktop or Documents
     (right-click it, "Extract All...").
  2. Copy your Pac-Man ROM (the .nes file, any name) into the new folder.
  3. Double-click PacManRecomp.exe. If Windows shows "Windows protected
     your PC", click "More info", then "Run anyway".
  4. The launcher finds the ROM by itself. Press Play.
     (Or skip step 2 and pick the ROM in the launcher.)

The first time you play, the game sets itself up from your ROM: a small
window shows it working for a few seconds, then it deletes the tools it
used. After that it starts straight away. You can move the game's folder
anywhere.


WHAT YOU NEED
  - Windows 10 or 11 (64-bit)
  - Your own Pac-Man ROM: Pac-Man (USA) (Namco), a .nes file. It must be
    the Namco release; the Tengen version won't work.


WHY THE GAME SETS ITSELF UP FROM YOUR ROM
  A recompiled game works by translating the cartridge's program into C and
  compiling it. The result contains Pac-Man's own game code, which belongs
  to Bandai Namco and can't be shared. So this download holds only the
  project's own program, with no game code in it, plus two small free tools
  (in the tools folder): the recompiler and TinyCC, a tiny C compiler. On
  your PC they translate your ROM and compile it into game.dll, next to the
  game. That file is made from your ROM, so like the ROM, it's yours: don't
  share it.
  Some other projects ship a ready-made .exe, but that .exe still contains
  the publisher's game code. Making it on your PC, from a ROM you own, is
  the safest way we know to do it. (Our understanding, not legal advice.)


KEYS (PLAYER 1)
  Arrow keys = move     Enter = Start / pause     \ (backslash) = Select
  Z = A     X = B     Esc = pause menu
  The launcher's Controls page shows all keys and gamepad buttons. Change
  them in Settings, with Configure under each player.


UPDATES
  The launcher can check for new versions: tick "Check for updates on
  startup" or press "Check for updates now" (off by default, so the game
  doesn't go online unless you ask). An update downloads and installs the
  new version, keeps your settings, high scores and mods, and the game sets
  itself up again from your ROM (a few seconds).


IF SOMETHING GOES WRONG
  - A message says what the problem is (wrong ROM, missing files...).
  - If setting up fails, a file called setup-log.txt in the game folder
    explains why. Some antivirus programs block it, because it makes program
    code on your PC: allow the game folder and try again.
  - Include setup-log.txt if you ask for help on the GitHub page:
    https://github.com/Mr-Shizzy/PacManRecomp/issues


WHAT'S IN THIS FOLDER
  PacManRecomp.exe    the game: double-click it
  SDL2.dll            part of the game (graphics, sound, gamepads)
  assets\             the launcher's pictures and fonts
  tools\              the recompiler and TinyCC: used once to set the game
                      up, then deleted
  licenses\           the licenses of everything included
  Modding guide.md    how to make mods
  game.dll            made from your ROM the first time you play
