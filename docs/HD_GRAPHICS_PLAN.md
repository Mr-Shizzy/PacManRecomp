# Mods: beginner-friendly graphics, sounds and mod selection — plan

Status: planning (not implemented).

## Goal

Let an absolute beginner replace Pac-Man's graphics by painting ordinary
image files, one per recognisable thing, with no tile sheets, maps or
`hires.txt`. Mesen HD packs keep working for people who have one.

## Decisions (agreed 2026-09-28)

- **Individual images** in `mods/graphics/` next to the exe, one file per
  graphic, named for what it is.
- **Separate files per direction with mirror fallback:** `left_1.png` is used
  if present, otherwise the game mirrors `right_1.png` (same for up/down).
- **Maze as one picture:** `maze.png`, plus optional `maze_flash.png` for the
  white flash when a level is cleared.
- **Any file may be missing:** that graphic stays original.
- **Any size:** each image is scaled to fit; it only has to keep the original's
  shape (e.g. square for Pac-Man). The guide lists every original size.

## Mods folder

Every mod is a folder inside `mods/` next to the exe. A mod may contain
graphics, sounds, or both; anything it lacks stays original.

```
mods/
  Arcade Remaster/
    mod.txt            optional: name, author, description
    preview.png        optional: thumbnail shown in the menu
    graphics/          individual images (layout below) + logo.png
    sounds/            start.wav, siren.wav ... (see MODDING.md)
  Spooky Halloween/
    ...
  Some Mesen Pack/     a folder with hires.txt counts as a graphics mod
    hires.txt ...
```

- **Choosing (agreed 2026-09-28):** one mod at a time, in a new
  `OPTIONS > MODS` screen in the game's own style. Default **NONE** (the
  original game). Choosing applies **instantly** (graphics and sounds reload
  live) and is saved.
- The MODS screen lists each mod's name and shows its description and
  `preview.png` (drawn sharp, as a runner overlay).
- Old locations (`sounds/` and `logo.png` next to the exe, `hdpack/`) keep
  working as a built-in "loose files" mod.

## How it works

1. **Capture (research, one-time):** log what the game draws during play,
   deaths, intermissions and the attract demo: which tiles, flips and color
   sets make up each frame of each graphic. Curate that into a built-in
   layout table (graphic name -> tiles, positions, flips, palette).
2. **Loader (at startup):** for each file present, scale it to the pack's
   resolution, cut it into 8x8-tile pieces per the layout table, and register
   them with the runner's existing HD engine keyed by tile + color set (so
   each ghost can look different). Missing mirrored files are generated by
   flipping. `maze.png` / `maze_flash.png` become HD background images shown
   while the maze is on screen.
3. **Starter generator:** `tools/make_hd_template.py` writes the whole
   `mods/graphics/` tree from the user's ROM, every file an enlarged copy of
   the original in its **real colors**, ready to paint.
4. **Guide:** docs/MODDING.md gets a beginner walkthrough with a table of
   every file, what it is and its original size.

## Work order

1. Mods folder + MODS menu (list, description, preview, instant switch) for
   the parts that already exist: sounds, logo, Mesen packs. Needs a runner
   call to reload the HD pack while running.
2. Capture: which tiles/flips/colors make up each graphic.
3. Individual-image loader + starter-tree generator.
4. Beginner guide rewrite (MODDING.md), including a sample mod layout.

## Risks

- Tiles shared between graphics (e.g. a piece used by two animation frames):
  the last file to claim a tile wins. The capture step will show where this
  happens; the guide will say which files must match.
- The maze image must line up with the game's maze grid; the guide will give
  the exact size and the starter file will show the alignment.
